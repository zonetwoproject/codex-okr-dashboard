# Mark2 작업 폴더 가이드

이 폴더는 Mark2 전용 산출물(와이어프레임, 화면 설계 메모, 임시 자산)을 분리 보관하기 위한 공간입니다.

운영 원칙:
- 실제 앱 소스는 기존 `prototype/public`, `prototype/src`를 계속 사용합니다.
- 버전 분리는 폴더 복제가 아니라 Git 브랜치(`main`, `mark2`)로 관리합니다.
- 이 폴더에는 문서/참고 자산만 저장하는 것을 권장합니다.

예시:
- `prototype/mark2/ui-spec.md`
- `prototype/mark2/assets/`
