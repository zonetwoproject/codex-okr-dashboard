# OKR Dashboard Operations Runbook v1.0

작성일: 2026-02-14

## 1. 목적
월간/반기 운영 루틴을 표준화하고, 데이터 정합성과 감사 가능성을 유지한다.

## 2. 운영 역할
- Admin: 정책/권한/마스터 데이터
- PM: Objective/KR/Initiative 관리, 리뷰 준비
- Analyst: 실험 데이터 연동, 품질 점검
- Leadership: 리뷰 승인, 방향성 조정

## 3. 월간 운영 절차 (M1~M12)
1. 월초 데이터 준비
- 전월 실적 누락 체크
- source_type 분포 확인(manual 비율 과다 여부)

2. 실적 입력/동기화
- manual 입력 수행
- 연동 가능 데이터는 synced 반영
- 중복 입력은 upsert로 정리

3. KR 상태 점검
- 달성률 재계산
- 신호등 업데이트
- 기여 실험 분포 확인(weight 왜곡 여부)

4. 리뷰 준비
- KR Detail 핵심 이슈 3개 선정
- 리스크/액션 기록

5. 감사 로그 확인
- 목표값/정의/상태/링크 변경 이력 검토
- actor/reason 누락 로그가 있으면 즉시 보정

## 4. 반기 운영 절차 (H1/H2)
1. 반기 시작
- 반기 생성(H1/H2)
- 이전 반기 템플릿 선택 복제

2. 반기 중
- 목표 수정 허용, 단 변경 이력 필수
- 대규모 수정 시 leadership 승인 기록

3. 반기 종료
- KR 달성률 확정
- 기여 실험 결과 회고
- 다음 반기 개선 과제 도출

## 5. 장애/예외 대응
1. 연동 실패
- 재시도 큐 확인
- 지연 24시간 초과 시 manual fallback

2. 지표 이상치
- 원천 데이터 vs 저장값 대조
- source_type이 calculated인 값 우선 재계산

3. 감사 로그 누락
- 누락 변경건 추적 후 수동 보강
- 재발 방지: API 입력 필드 검증 강화

## 6. 백업/복구
- 백업 주기: 일 1회
- 복구 리허설: 월 1회
- 복구 목표: 핵심 API 30분 내 정상화

## 7. 운영 KPI
- 월 실적 입력 완료율 95%+
- manual 비율 점진 감소
- 리뷰 액션 완료율 80%+
- 감사 로그 누락 0건

- [ ] 월 실적 upsert 정상

- [ ] 신호등 임계값 적용 정상
- [ ] 감사 로그 필수값 누락 없음
